# To-Do List Application

A simple and interactive To-Do List application developed using HTML5, CSS3, and Vanilla JavaScript.

## Project Overview

This project is designed to help users organize and manage their daily tasks. Users can create, view, edit, delete, and complete tasks through a simple interface.

The application uses browser LocalStorage to automatically save tasks and retain them even after refreshing or reopening the browser.

## Features

- Create new tasks
- View all tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks by All, Active, and Completed
- Automatically save tasks using LocalStorage
- Dynamic DOM manipulation
- Event delegation for task interactions
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser LocalStorage

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your tasks.
